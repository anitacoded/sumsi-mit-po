Labelled action button – primary for the one main action per view (Start, Öffnen), secondary for alternatives, ghost for low-emphasis (Zurück-Links, Abbrechen).
```jsx
<Button icon="play" size="lg" block>Start</Button>
<Button variant="secondary" iconRight="external-link" href={url} target="_blank">Auf YouTube öffnen</Button>
```
Sizes sm 40 / md 48 / lg 56px tall. Not a pill – radius 12px. Sentence case, never ALL CAPS.
